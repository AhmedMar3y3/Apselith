# APSELITH visual identity

## Idea

An orbital monogram: a circular Earth reference, an inclined trajectory and a single amber satellite. The central diamond suggests a scientific instrument reticle. The mark stays geometric and readable at favicon size; no raster image or external font is required.

## Assets

- `public/brand/apselith-mark.svg`: transparent symbol and favicon.
- `public/brand/apselith-wordmark.svg`: horizontal logo with descriptor, intended for dark backgrounds.
- `public/brand/apselith-social.svg`: editable 1200 × 630 promotional artwork.

The application uses the same mark in its header. Preserve its proportions and leave at least one quarter of the symbol width as clear space. Use the amber accent for a selected object or single emphasis rather than recoloring every interface control.

## Palette

| Role                  | Color     |
| --------------------- | --------- |
| True black background | `#000000` |
| Charcoal panel        | `#080808` |
| Primary text          | `#E8E8E8` |
| Secondary text        | `#929292` |
| Orbit cyan            | `#89E2E6` |
| Selected-object amber | `#F1C57D` |
| Relief-heart rose     | `#E28FA5` |

Typography uses the local Segoe UI/system sans family for interface text and monospace for times and measured values. Uppercase, spaced micro-labels distinguish context from content. Large, light numerals carry primary scientific results. Motion is restrained and reduced-motion preferences must be respected.

## APSELITH name

The product, wordmark, favicon asset paths, social artwork, page metadata and package are named APSELITH. Existing private IndexedDB/localStorage namespaces remain unchanged to preserve catalogs and saved favorites for existing users.
